JEI-3D FPS AIM TRAINER

Sube estos 4 archivos a la raíz del repositorio:
- index.html
- manifest.webmanifest
- sw.js
- icon.svg

GitHub Pages:
Settings > Pages > Deploy from a branch > main > /(root) > Save.
Abre el sitio publicado en Chrome Android y usa menú ⋮ > Instalar aplicación.

Controles:
- Joystick izquierdo: movimiento.
- Arrastrar el área de juego: girar cámara.
- APUNTAR: acercar la mira.
- DISPARAR: disparo.
- REC: reinicia los objetivos.
- Ⅱ: pausa.

Es un simulador de entrenamiento independiente con gráficos 2D/canvas y perspectiva FPS simulada; no modifica Blood Strike ni reproduce su motor o recursos.
